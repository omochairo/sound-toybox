# sound-toybox

「おととかたちのピタゴラパズル」 - 3〜10歳向けの、音の鳴る物理パズルのおもちゃです。
画面にブロックを置くと、落ちてきたボールが当たって、きれいな音が鳴ります。
年齢に合わせて 3 つのモード（3〜5さい・6〜8さい・9〜10さい）があります。

## あそびかた

| 年齢 | モード | できること |
|---|---|---|
| 3〜5さい | おもちゃばこ | まる・さんかく・しかくを置くと、落ちてくるボールが当たって音が鳴る |
| 6〜8さい | ルートパズル | さかみち・ジャンプ・ベルトでボールをゴールの⭐まで運ぶ（5 ステージ。クリアすると★が付く） |
| 9〜10さい | ピタゴラおんがく | 重力・まさつ・テンポを変え、はぐるまやおんぷ・ドラムで音楽を作る |

- **タップ**: ブロックを置く／落ちてくるボールをタップすると、はじける
- **ドラッグ**: ブロックを動かす（はぐるま・モーターは置いた場所に固定）
- **2 回タップ**: ブロックを 45 度回す（ドラムは音色の切り替え。おんぷは回さず、1 回目で開いたピアノが 2 回目で閉じる）。ジャンプ台は板の ▲ の向きに、いつも同じ強さで跳ばすので、傾けると斜めに跳ばせる
- **長押し**: ブロックを消す（「けす」ボタンで全部消す）
- **おんぷ**: タップでピアノを開き（開いているときにもう一度タップすると閉じる）、鍵盤で音の高さを選ぶ
- 指は 1 本ずつ: ブロックを押している間は、ほかの指で触っても無視する

## 動かす

ビルドは不要です。静的ファイルをそのまま配信します（GitHub Pages）。手元では:

```bash
python -m http.server 8000
```

物理エンジン [Matter.js](https://brm.io/matter-js/) 0.19.0（MIT）は `vendor/` に同梱しています（CDN が使えない環境でも動くように）。

## テスト

`index.html` と `app.js` を jsdom の中で丸ごと動かし、操作・物理・音・ステージを確かめます（canvas と Web Audio は差し替え）。
GitHub Actions でも PR ごとに実行します。

```bash
npm ci
npm test
```
